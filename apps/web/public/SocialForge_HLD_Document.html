3. Core Subsystems & Component Design

3.1 Frontend Presentation Layer (apps/web)

  • Stack: React 18, TypeScript, Vite, Vanilla CSS Design System with dark mode glassmorphism.
  • Content Studio & Composer: Multi-channel composer with real-time character counters, brand voice compliance meters, and live device mockups for Instagram, X, LinkedIn, and TikTok.
  • AI Design Studio: Canvas visual layer editor allowing text, shapes, badges, and image layers with drag-and-drop, aspect-ratio switching (1:1, 4:5, 9:16), and SVG rasterization.
  • Reel Motion Studio: 9:16 vertical short-form video creator with AI storyboarding, subtitle styling, and audio track pairing.
  • Calendar & Timeline Engine: Interactive visual planner supporting week/month views, drag-and-drop rescheduling, and timezone localization.

3.2 Backend REST API Service (apps/api)

  • Stack: Node.js, Express, TypeScript, Knex.js SQL query builder.
  • TenantContext Middleware: Extracts and verifies JWT on every request; enforces tenant_id scoping across all database operations.
  • CryptoVault Service: AES-256-GCM authenticated encryption for OAuth access tokens and client secrets stored in MySQL.
  • SSRF Shield: Validates all incoming external asset URLs, enforcing public IP resolution and blocking access to loopback (127.0.0.1), private RFC1918 subnets (10.0.0.0/8, 192.168.0.0/16), and cloud metadata IP (169.254.169.254).
  • In-Memory Sliding-Window Rate Limiter: Brute-force protection returning HTTP 429 with standard RateLimit-* and Retry-After headers.

3.3 AI Brain & Generation Engine

  • Engine: OpenAI GPT-4o with Structured JSON Output enforcement.
  • Brand Kit Compliance: Automatically injects brand tone, target personas, prohibited taboo words, and mandatory legal disclaimers into LLM system prompts.
  • 10 Specialized Formats & 11 Transformation Modes: Formats for Instagram captions, X threads, LinkedIn thought leadership, TikTok scripts, and multi-language translation.

3.4 Dynamic Graphic & Video Rendering Subsystem

  • SVG & Image Template Engine: Generates production-ready vector graphics dynamically across 4 standard aspect ratios: 1:1, 4:5, 1.91:1, and 9:16.
  • Native FFmpeg 9:16 Video Engine: Fully automated video rendering pipeline generating 1080×1920 (9:16) portrait MP4 files with H.264 video and AAC audio codecs. Dynamic Gaussian boxblur backdrops, hardcoded ASS subtitle burn-in, and dynamic sidechain audio ducking.

6. Non-Functional Requirements & Security Architecture

Category Requirement Architectural Implementation
Data Isolation Strict Multi-Tenant Separation Every SQL query enforces tenant_id and brand_id. Foreign key cascade rules.
Secret Management Zero Plaintext Credentials Social tokens encrypted with AES-256-GCM with unique initialization vectors (iv) and auth tags.
SSRF Prevention Cloud Metadata Leakage Defense URL validation resolves hostnames, checks IP ranges, and blocks loopback, private RFC1918 subnets, and 169.254.169.254.
Rate Limiting Brute-force Shield In-memory sliding-window limiter on sensitive endpoints (/auth/*, /publish-now). Returns HTTP 429.
Timezone Precision Deterministic Multi-Timezone Scheduling Schedules computed via Luxon brand-local conversion and stored in UTC; executed via BullMQ queue timers.
Publishing Idempotency Zero Duplicate Posts Status locks prevent race conditions during parallel publish triggers or retry attempts.
