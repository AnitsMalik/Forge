# User Flows & Journeys

## Key Journeys
1. **Onboarding & Workspace Setup**:
   - Register account -> Create Workspace -> Invite Team -> Connect Social Channels.
2. **Autonomous Campaign Launch**:
   - Define Brand Voice -> Set Campaign Goals -> AI Generates Content Calendar -> Approval Gate -> Auto-publishing.
3. **Connect Hub Integration**:
   - Connect Google Drive / Meta -> Discover Resources -> Map Assets to Workspaces.
4. **Approval & Review Workflow**:
   - Internal team drafts post -> Review requested -> Magic review link sent to external stakeholder -> One-click approval/rejection.
