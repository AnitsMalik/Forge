# Shopify Integration

## Overview
Connects e-commerce stores to trigger dynamic social promotions when new products launch, prices drop, or inventory reaches key thresholds.

## Features
- Shopify Admin GraphQL API integration.
- Webhook subscriptions: `products/create`, `products/update`, `inventory_levels/update`.
- Auto-extracts product photography, descriptions, variant prices, and store links into SocialForge marketing objects.
